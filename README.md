# 📚 Online Bookstore SQL Project

## 📌 Project Overview
This project focuses on analyzing an Online Bookstore database using PostgreSQL. It explores book sales, customer details, revenue, and inventory through SQL queries.

## 🛠️ Tools Used
- PostgreSQL
- SQL
- pgAdmin 4

## 📊 SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- INNER JOIN, LEFT JOIN
- Aggregate Functions (SUM, AVG, COUNT)
- DISTINCT, LIMIT, BETWEEN
- COALESCE()

## 🔍 Key Analysis
- Total revenue generated from book sales.
- Top-selling and most expensive books.
- Customer purchase analysis.
- Genre-wise book sales.
- Total books sold by each author.
- Remaining book stock analysis.

## 📁 Project File
- `Online_Bookstore.sql` – Database creation and SQL queries.
